## 📖 概要

**「誠実さこそが、究極のアルゴリズムである。」**

彼に必要だったのは、派手なキーノートでも壮大なビジョンでもなかった。憲法（Constitution）と、物理法則だけだった。

2026年2月、シリコンバレーは奇妙な静寂に包まれていた。「AGIはいつ来るか」という喧騒はもうない。代わりに訪れたのは、SaaSの断末魔である。人間がログインし、ボタンを押し、データを入力するための「UI」を持つソフトウェアが、不要になった。AIエージェント同士がAPIを通じて直接会話し、タスクを完遂する時代——本書はこれを「**Coworkショック**」と呼ぶ。

そしてこの静かなる革命の震源地にいたのは、火星移住を語る経営者でも、各国首脳と握手する経営者でもなかった。くたびれたパーカーを着て、数式と確率論について淡々と語る物理学者、ダリオ・アモディである。

本書は、この人物を一貫した問いで追う。**なぜ、最も退屈な男が勝ったのか。** 答えは「信頼（Trust）」である。他社が創造性やマルチモーダルの華やかさを競っている間、アモディはただ一つのことを狂気的なまでに追求し続けた。詩を書かせるなら他でもいい。だが銀行口座を操作させ、機密データを扱わせるなら——企業はそこで選択を迫られる。

**安全性は、かつて開発速度を落とすブレーキだと嘲笑されていた。** だがアモディは証明した。ブレーキの性能が良いからこそ、F1カーは最高速でコーナーを曲がれるのだと。本書は、スケーリング則の発見、OpenAIからの集団離脱、公益目的法人（PBC）という砦、憲法AI、メカニスティック・インタープリタビリティ、そして「圧縮された21世紀」というビジョンまでを、一次資料をもとにたどるOSS書籍である。
